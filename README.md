# Guess My Number

A small browser game built with vanilla **HTML**, **CSS** and **JavaScript**. The game picks a secret number between 0 and 20, and you try to find it in as few guesses as possible.

![HTML5](https://img.shields.io/badge/HTML5-E34F26?style=flat-square&logo=html5&logoColor=white)
![CSS3](https://img.shields.io/badge/CSS3-1572B6?style=flat-square&logo=css3&logoColor=white)
![JavaScript](https://img.shields.io/badge/JavaScript-F7DF1E?style=flat-square&logo=javascript&logoColor=black)

## How to play

1. Type a number between 0 and 20 and click **Check!**
2. The game tells you whether your guess is **too high** or **too low**.
3. Every wrong guess costs one point from your score, which starts at 20.
4. Guess correctly and the screen turns green. Your best score is saved as the **high score**.
5. Click **Again!** to start a new round with a new secret number.

## Features

- Input validation for empty and out-of-range guesses
- Live score and high-score tracking across rounds
- Visual feedback when you win
- No frameworks or build step, just open `index.html`

## Run it locally

```bash
git clone https://github.com/samsondebebe/js-learning.git

```

Then open `index.html` in your browser.
